
# HR Analytics Dashboard – Excel

## Project Overview
This project presents an interactive HR Analytics Dashboard developed using Microsoft Excel. The dashboard helps analyze employee demographics, workforce status, attrition, department performance, salary bands, and employee distribution across locations.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis and Visualization

## Key Performance Indicators (KPIs)
- Total Employees: 2,500
- Active Employees: 1,899
- Male Employees: 1,276
- Female Employees: 1,224
- Attrition Rate: 24%

## Dashboard Features
- Employee Count by Department
- Employee Status Distribution
- Attrition Rate by Salary Band
- Attrition by Performance Level
- Gender-wise Employee Distribution
- Attrition Rate by Department
- Employee Count by Location
- Interactive filters for location, job title, department, age group, salary band, and other HR attributes

## Project Objective
The objective of this project is to transform HR data into meaningful visual insights that help organizations monitor workforce trends, understand employee attrition, and support data-driven HR decisions.

## Key Insights
- The dashboard summarizes a workforce of 2,500 employees.
- Active employees account for the majority of the workforce.
- The reported attrition rate is 24%.
- The dashboard compares employee distribution across departments and locations.
- Salary bands and performance levels can be explored to understand attrition patterns.
